# الـ Worker — طلبات المشاريع ومختبر الأفكار

هذا كود صغير بيشتغل على سيرفرات Cloudflare. بيعمل شغلتين موقعك ما بيقدر يعملهم لحاله
(لأنه ملفات ثابتة على GitHub Pages):

| الرابط | شو بيعمل |
|---|---|
| `POST /brief` | بياخد طلب المشروع من الفورم ← بيبعتلك إيميل + تنبيه تيليجرام |
| `POST /idea` | بيولّد فكرة تسويقية بالذكاء الاصطناعي لمختبر الأفكار |
| `GET /health` | فحص سريع إنه شغّال — بتفتحه بالمتصفح |

---

## المفاتيح السرّية

**ولا مفتاح مكتوب بأي ملف هون، وهاد مقصود.** الملفات بترفع على GitHub، وأي مفتاح
بينكتب فيها بيصير مكشوف للعالم. المفاتيح بتنحط بأوامر منفصلة وبتضل مخزّنة عند
Cloudflare مشفّرة:

```bash
npx wrangler secret put RESEND_KEY
npx wrangler secret put TELEGRAM_BOT_TOKEN
npx wrangler secret put TELEGRAM_CHAT_ID
```

كل أمر بيسألك عن القيمة، بتلصقها، بتضغط Enter. **ما بتظهر عالشاشة وما بتنحفظ بجهازك.**

---

## الأوامر

```bash
npm install          # مرة وحدة
npx wrangler login   # بيفتح المتصفح عشان تسجّل دخول — انت بتسجّل مش أنا
npm run deploy       # بينشر
npm run logs         # بيوريك الطلبات وهي بتوصل — مفيد لما إشي ما يزبط
```

---

## تبديل موديل الذكاء الاصطناعي

هلق شغّال على موديلات Cloudflare المجانية. لو بدك تبدّل لكلود (جودة أعلى، بدّه دفع):
غيّر دالة `askAI()` بآخر `src/index.js` وبس — باقي الملف ما بيتغيّر، ولا الموقع.

## الحماية الموجودة

- **قائمة مواقع مسموحة**: أي موقع تاني بيحاول يستدعي الـ Worker بينرفض. بدونها حدا
  تاني بيقدر يستهلك رصيدك ويبعتلك طلبات وهمية.
- **فخّ سبام**: حقل مخفي بالفورم ما بيشوفه إنسان. لو انتعبّى فهو روبوت — بنرجّعله
  «تمام» وما بنبعت إشي، عشان ما يعرف إنه انكشف ويجرّب طريقة ثانية.
- **تنظيف المدخلات**: كل نص جاي من الزائر بينقصّ وبينشال منه أي محارف تحكّم قبل ما
  ينحط بإيميل.
- **فشل صريح**: لو ولا إيميل ولا تيليجرام وصلوا، الـ Worker بيرجّع خطأ عشان الفورم
  يعرض للزائر زر «انسخ الطلب» — بدل ما يقوله «تم» وهو ما وصل.
